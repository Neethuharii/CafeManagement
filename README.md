# ☕ Cafe Management System

A web-based Cafe Management System developed using **PHP** and **MySQL** to simplify cafe operations. The system helps cafe staff efficiently manage orders, menu items, and customer billing while enabling cafe owners to monitor sales records and generate reports.

## 📌 Features

### Staff Module

* Manage customer orders
* Add, update, and delete menu items
* Generate customer bills automatically
* View order details and status
* Fast and user-friendly interface

### Admin Module

* Dashboard with sales overview
* Manage menu categories and products
* Track customer transactions
* Monitor business performance

## 🛠️ Technology Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server:** Apache (XAMPP)

## 🚀 Installation

### Prerequisites

* PHP 7.4 or higher
* MySQL
* Apache Server
* XAMPP

### Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/Cafe-Management-System.git
```

2. Move the project folder to your server directory:

* XAMPP: `htdocs`

3. Create a MySQL database:

```sql
CREATE DATABASE cafe_management;
```

4. Configure database credentials in the configuration file:

```php
$host = "localhost";
$user = "root";
$password = "";
$database = "cafe_management";
```

6. Start Apache and MySQL.

7. Open your browser and visit:

```text
http://localhost/Cafe-Management-System
```
